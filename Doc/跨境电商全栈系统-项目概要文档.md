> **状态快照（2026-09-03，以代码为准）**
>
> 本项目当前采用根目录单模块 Maven 构建，并非文档早期规划的 `mall-system/` 多模块结构。B 端运营后台已经具备可运行的管理页面和 API；C 端购物车、会员地址、收藏/浏览、下单、支付回调、物流等后端 API 已落地，但 C 端用户前端尚未实现；`mall-ai-service/` 目前只有 Python 包目录骨架，AI Agent、RAG、SSE 和评测功能仍处于设计阶段。

## 一、项目概述

### 1.1 项目定位

从"跨境电商后台管理系统"升级为**完整的跨境电商全栈系统**，实现电商业务闭环：

```
用户浏览 → 购物车 → 下单 → 支付 → 物流 → 售后
                ↕
          B端运营管理（商品/订单/会员/营销/财务）
                ↕
          AI 智能客服（自然语言交互）
```

### 1.2 三大子系统

| 子系统 | 用户 | 核心能力 | 状态 |
|--------|------|---------|------|
| **B 端运营后台** | 店长/运营/客服/财务 | 商品/订单/会员/营销/财务管理 + RBAC 权限 | ✅ 已实现 |
| **C 端用户前台** | 消费者 | 商品浏览/购物车/下单/支付/物流追踪 | 📋 设计完成 |
| **AI 智能客服** | 两端用户共用 | Agent、RAG、工具调用、SSE、评测与人工接管 | 📋 按实施方案落地 |

## 二、B 端运营后台（已实现）

### 2.1 角色体系

| 角色 | 职责 | 权限范围 |
|------|------|---------|
| **店长 (Store Manager)** | 全局管理 | 全部权限 + 系统配置 + 审批退款/活动 |
| **运营专员 (Operations)** | 商品运营 | 商品上下架、分类配置、营销活动（无删除/定价权） |
| **客服专员 (CS)** | 订单服务 | 查看订单、处理退款、更新物流（不可改商品） |
| **财务专员 (Finance)** | 资金对账 | 对账单只读 + 导出 |

### 2.2 已实现模块

```
mall-system/
├── mall-common/          # 公共基类、统一返回、全局异常、基础配置
├── mall-security/        # JWT 认证 + Spring Security + @DataScope 数据权限
├── mall-system/          # 系统管理：用户/角色/菜单 CRUD
├── mall-product/         # 商品管理：SPU/SKU/分类/品牌/库存
├── mall-order/           # 订单管理：全生命周期 + 退款 + MQ 异步
├── mall-member/          # 会员管理：资料/地址/积分
├── mall-marketing/       # 营销管理：优惠券/活动/秒杀
├── mall-finance/         # 财务管理：对账单/EasyExcel 导出/关税配置
├── mall-search/          # ES 搜索引擎：商品全文检索
└── mall-web/             # 统一入口 + 所有 Controller
```

### 2.3 权限实现

- **后端:** Spring Security `@PreAuthorize` + JWT Token，按钮级权限点 (`product:spu:add` 等)
- **数据权限:** `@DataScope` 注解 + AOP 切面自动拼装 SQL 过滤
- **前端:** 路由守卫动态过滤菜单 + `v-permission` 指令按钮级控制

### 2.4 高并发设计（已实现）

| 场景 | 方案 |
|------|------|
| **库存扣减** | Redis 预扣 + MQ 异步削峰 + DB 乐观锁兜底 |
| **分布式锁** | Redis NX/EX 防超卖 |
| **消息队列** | RabbitMQ 解耦订单创建/支付/退款/ES 同步 |
| **商品缓存** | Redis String/JSON 30min TTL，手动失效 |
| **搜索** | ES 8 ik_smart 分词 + 增量同步 |

| **mall-product** | 商品服务（C 端查询扩展） | 复用 pm_spu / pm_sku / pm_sku_stock |

### 3.2 核心业务流程

```
购物车流程: 添加商品 → 校验库存 → 选中结算
下单流程:   校验参数 → Redis Lua 预扣库存 → 价格计算 → 生成订单 → MQ 异步扣 DB 库存 → 清空购物车
支付流程:   创建支付单 → 调用支付宝/微信沙箱 → 异步回调 → 更新订单状态
物流流程:   商家发货 → 填写物流单号 → 定时任务模拟轨迹 → 用户确认收货
```

### 3.3 订单状态流转

```
待支付 → 待发货 → 待收货 → 已完成
  │         ↑         ↑
  ├→ 已取消   发货     确认收货
  └→ 退款中 → 已退款
```

## 四、AI 智能客服系统

### 4.1 双层架构

```
Vue 3 Frontend（AI 聊天气泡 + SSE 打字机效果）
        │ REST + SSE
Spring Boot 业务层（鉴权/事务/持久化/请求转发）
        │ HTTP 转发
Python FastAPI AI 微服务层（LangGraph Agent 编排）
        │ LLM API
Claude / GPT-4o
```

**设计原则:**
- **Java 层**：锚定业务（事务、鉴权、持久化、高并发）
- **Python 层**：锚定 AI（LangChain、LangGraph、Embedding、Agent 编排）
- 两套服务各自 Docker 容器部署，通过 HTTP + SSE 通信

### 4.2 Agent 工作流 (LangGraph)

```
用户输入 → 意图识别 → 条件路由
                        ├→ 简单问答 → RAG 检索 (ES dense_vector + BM25)
                        ├→ 复杂任务 → 多步 Agent 协作 (Function Calling)
                        ├→ 查订单/退货 → Spring Boot API 调用
                        └→ 打招呼 → 直接回复
                        ↓
                   质量检查 (LLM 自检) → SSE 流式输出
```

### 4.3 Function Calling 工具集

| 工具名 | 触发场景 | 调用后端 API |
|--------|---------|-------------|
| `query_order` | "查一下我的订单" | `GET /api/order/by-order-no/{orderNo}` |
| `query_product` | "这个商品还有吗" | `GET /api/product/spu/{id}` |
| `check_return_eligibility` | "能退货吗？" | `GET /api/order/refund/check-eligibility/{orderNo}` |
| `track_logistics` | "货到哪了" | `GET /api/order/{id}/logistics` |
| `search_products` | "帮我找找红色裙子" | `GET /api/search/product?keyword=...` |
| `query_user_orders` | "我的订单列表" | `GET /api/trade/order/list`（C 端扩展） |
| `query_cart` | "我的购物车" | `GET /api/trade/cart`（C 端扩展） |

### 4.4 RAG 混合检索

```
用户问题 → Query Rewrite (LLM 改写)
        → 双路召回: BM25 (关键词) + dense_vector (语义)
        → 合并 Top 20 → Rerank (LLM 精排 Top 5)
        → LLM 增强生成
```

利用已有的 Elasticsearch 8 `dense_vector` 字段类型，无需额外向量数据库。

### 4.5 SSE 流式输出全链路

```
Python FastAPI  StreamingResponse
        → Spring Boot SseEmitter 转发
        → Vue 3 EventSource 接收
        → 增量追加 + 光标闪烁效果
```

### 4.6 评测体系（核心差异化）

| 环节 | 方法 |
|------|------|
| **离线评测** | 50-100 条测试集 × 每次 Prompt 改动全量回归 |
| **LLM-as-Judge** | 另一个 LLM 对比期望回答 vs 实际回答打分 |
| **在线监控** | LangFuse Trace + 用户点赞/点踩反馈 |
| **可对比实验** | 换模型/改 Prompt/调整检索策略 → 量化指标对比 |

### 4.7 项目结构

```
Spring Boot (Java 模块):
  mall-ai/
  ├── controller/    AiChatController (SSE), AiKnowledgeController, AiEvalController
  ├── service/       AiChatService, AiKnowledgeService, AiEvalService
```
