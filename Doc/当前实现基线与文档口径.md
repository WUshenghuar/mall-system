## 1. 实际架构

当前仓库不是早期文档规划的多 Maven 模块或独立微服务，而是：

```text
根目录单 Maven 模块（Java 23 / Spring Boot 3.2.5）
└── com.mall
    ├── product / order / trade / member
    ├── marketing / finance / search / security / system
    └── web（统一 Spring Boot 入口和 Controller）

mall-web/          Vue 3 + Ant Design Vue，B 端运营控制台
mall-storefront/   Vue 3 + Vant，C 端响应式交易前台（移动优先 + 桌面自适应 ≥1025px）
mall-ai-service/   Python FastAPI + LangGraph，已实现 AI 客服 P0 对话基线
```

基础设施由 Docker Compose 提供：MySQL `3306`、Redis 宿主机 `16379`（容器 `6379`）、RabbitMQ 宿主机 `18110/18111`（容器 `5672/15672`）、Elasticsearch 宿主机 `19200`（容器 `9200`）、MinIO 宿主机 `18120/18121`（容器 `9000/9001`）。

## 2. 当前已实现

- B 端：商品、分类、品牌、SKU、基础库存、订单、会员、营销、财务、税率、系统用户/角色和订单看板；看板支持今日/过去 24 小时订单聚合、24 个小时桶、30 秒轮询和 Redis Pub/Sub 实时广播；交易售后页面已接入 C 端退款/退货退款申请的待审、驳回、退款和收货处理流程，并显示处理备注与退货物流。
- C 端后端：会员手机号密码认证、会员资料与积分流水、订单完成后的消费累计/积分奖励/等级更新及已完成订单退款回滚、匿名商品目录、购物车、国际地址、单币种订单、税率计算、收藏/足迹、结算复核、优惠券计算与核销、订单、库存预占/释放、物流和确认收货；结算会生成 15 分钟、一次性 Redis 快照 token，下单由服务端快照恢复商品、地址和优惠券并重新核算税费；同一订单支付单创建通过订单行锁复用待支付单，支付宝回调具备 RSA2 签名、金额、订单归属与幂等校验。
- C 端前台：`mall-storefront` 已提供账户、地址编辑、会员等级/积分/积分明细、国家地址、商品目录筛选/排序、商品详情、购物车、结算税费展示、优惠券/活动、订单详情、物流详情、待支付取消、待收货确认、收藏/足迹独立页、退款/退货退款申请与进度页及平台客服浮窗；活动商品可直达详情，客服支持 AI 流式回答、会话恢复和人工工单。退货退款支持凭证上传和提交退货物流。未登录访问交易页面会引导到会员登录。前台为移动优先的响应式布局：≤680px 保持移动单列与底部导航，≥1025px 自动切换桌面布局（顶栏横向导航、商品多列网格、内容限宽居中）。
- 退款闭环：C 端仅允许会员为自己的订单申请符合状态的售后，同订单处理中的申请不可重复创建；待发货支持仅退款，待收货/已完成支持退货退款。B 端审核通过或驳回，退货退款需经过用户提交物流、平台确认收货后完成退款；状态更新使用条件更新，驳回恢复原订单状态，完成后订单置为已退款并补回数据库、Redis 和活动库存。
- 营销活动：B 端活动表单已补齐活动类型和活动商品配置；活动商品通过 `mk_activity_sku` 唯一键管理 SKU、活动价、活动库存和每人限购，C 端按起止时间读取进行中的活动及关联 SKU；活动价会进入结算和订单明细快照，活动库存支持下单占用与取消释放；优惠券领取锁定券行并条件扣减发行量，保证每人限领一次，下单占用后取消或超时关单会恢复为可使用。
- 基础设施：Flyway（含 `V5__add_trade_refund.sql`、活动商品 V11/V12、订单活动快照 V13、退货退款 V14、交易税费 V15）、Redis Lua 多 SKU 预占与回补 TTL、Jedis Redis 客户端兼容 Java 23 Windows、RabbitMQ 事务后交易事件、Docker Compose、UTF-8 开发种子导入脚本。
- AI 客服 Demo：Java `/api/ai/chat` SSE 网关、`/api/ai/recent` 会话恢复、Python `/internal/chat`、LangGraph 本地 fallback、Elasticsearch BM25 知识检索和中文 FAQ 本地 fallback，以及订单/物流/退款/商品/优惠券/会员/税费七类只读工具；通过 `tool_call`/`sources` 事件展示执行依据，并在 Java 侧校验会员与资源归属。
- 人工接管：C 端可创建平台客服工单，B 端客服可按状态分页查看、原子认领和解决，工单与会话及会员绑定，权限由 `order:support:list/handle` 控制。

## 4. 启动与数据约定

1. 复制 `.env.example` 为 `.env`，填写本地凭据。
2. 执行 `docker compose up -d`。
3. 在仓库根目录直接执行 `mvn spring-boot:run`；Spring 会自动导入根目录 `.env`。
4. 开发种子数据使用 `powershell -ExecutionPolicy Bypass -File scripts/import_dev_seed.ps1 -Reset`，脚本强制以 `utf8mb4` 导入，禁止使用 PowerShell 文本管道直接喂给 `mysql`。
   开发种子会员（如 `13900000001`）密码为 `password`；已有数据卷需重新导入种子后使用该账号。
