# 跨境电商全栈系统 — 需求设计文档

> **版本:** v2.0
> **日期:** 2026-07-24
> **状态:** B 端 ✅ 已完成 / C 端 🔧 实现中 / AI 🔲 待实现
> **技术栈:** Java 23 + Spring Boot 3.2.5 + Spring Security + JWT + MyBatis-Plus 3.5.7 + MySQL 8 + Redis 7 + RabbitMQ + Elasticsearch 8 + Vue 3 + Ant Design Vue 4 + Vite 5 + Python 3.11 + FastAPI + LangGraph + LangFuse

---

## 1. 项目概述

### 1.1 项目定位

面向跨境电商企业的**全栈业务系统**，覆盖 C 端用户消费 + B 端运营管理 + AI 智能客服三大场景，实现完整的电商业务闭环：

```
用户浏览 → 购物车 → 下单 → 支付 → 物流 → 售后
    ↕
B 端运营管理（商品/订单/会员/营销/财务）
    ↕
AI 智能客服（自然语言交互）
```

### 1.2 三大子系统

| 子系统 | 用户 | 核心能力 | 状态 |
|--------|------|---------|------|
| **B 端运营后台** | 店长/运营/客服/财务 | 商品管理、订单处理、会员管理、营销活动、财务报表、RBAC 权限 | ✅ |
| **C 端用户前台** | 消费者 | 商品浏览、购物车、下单支付、物流追踪、个人中心 | 🔧 |
| **AI 智能客服** | 两端用户共用 | 自然语言查订单/商品/退货、RAG 知识库问答、LLM 评测 | 🔲 |

## 2. 角色体系

### 2.1 B 端角色（4 个）

| 角色 | 职责 | 权限范围 |
|------|------|---------|
| **店长 (Store Manager)** | 全局管理 | 全部数据 + 系统配置 + 审批退款/活动 |
| **运营专员 (Operations)** | 商品运营 | 商品上下架、分类配置、营销活动（无删除/定价权） |
| **客服专员 (CS)** | 订单服务 | 查看订单、处理退款、更新物流（不可改商品） |
| **财务专员 (Finance)** | 资金对账 | 只读对账单 + 导出报表 |

### 2.2 C 端角色

| 角色 | 核心操作 |
|------|---------|
| **消费者** | 浏览商品 → 加购 → 下单 → 支付 → 查物流 → 确认收货 → 退货申请 |

### 2.3 权限实现

- **后端:** Spring Security `@PreAuthorize` + JWT，按钮级权限点 (`product:spu:add` 等)
- **数据权限:** `@DataScope` 注解 + AOP 自动组装 SQL 过滤（店长看全部，运营看本分类，客服看分配订单）
- **前端:** 路由守卫 + `v-permission` 指令按钮级控制 + 动态菜单

## 3. B 端运营后台需求

### 3.1 商品管理

| 功能 | 需求描述 |
|------|---------|
| **SPU 管理** | 创建/编辑/删除 SPU，关联分类+品牌，多语言描述 (JSON)，HS Code 海关编码，原产国 |

### 3.2 订单管理

| 功能 | 需求描述 |
|------|---------|
| **订单生命周期** | 创建 → 支付 → 发货 → 签收 → 完成 / 取消 |

### 3.3 会员管理

| 功能 | 需求描述 |
|------|---------|
| **会员资料** | 邮箱/手机、昵称、性别、头像、等级 (普通/Gold/Platinum)、累计消费 |
| **收货地址** | 国际地址（国家/省/市/详细地址/邮编）、默认地址 |
| **积分体系** | 积分余额、积分变更日志（+/- + 原因） |

### 3.4 营销管理

| 功能 | 需求描述 |
|------|---------|
| **优惠券** | 定义（满减/折扣/包邮）+ 发放 + 审核流程（草稿→审核→发布→结束）、每人限领/总量控制 |
| **营销活动** | 活动配置（秒杀/折扣/满减）、起止时间、关联商品 |
| **秒杀** | 关联 SKU + 秒杀价 + 秒杀库存 + 每人限购 |

### 3.5 财务管理

| 功能 | 需求描述 |
|------|---------|

| **关税配置** | 按分类+原产国+目的国配置税率 (DUTY/VAT/SALES_TAX)、有效期 |

### 3.6 系统管理

| 功能 | 需求描述 |

| **菜单管理** | 多级菜单树（目录/菜单/按钮）、路由路径、组件路径、权限标识 |

### 3.7 搜索

## 4. C 端用户前台需求

### 4.1 商品浏览

| 功能 | 需求描述 |
|------|---------|
| **商品列表** | 分类筛选、关键词搜索、价格排序、分页加载 |
| **商品详情** | 图片轮播、规格选择、价格展示（USD）、加购/收藏 |
| **浏览历史** | 自动记录浏览过的 SPU、列表查看 |

### 4.2 购物车

| 功能 | 需求描述 |
|------|---------|
| **添加商品** | 选择 SKU + 数量 → 加入购物车，已存在则累加数量 |
| **购物车列表** | 展示 SKU 图片/名称/单价/数量/选中状态/小计 |
| **修改数量** | +/- 增减，库存上限校验 |
| **选中结算** | 全选/单选，已选商品总价汇总，去结算跳转 |
| **删除** | 单个删除、批量删除 |

### 4.3 下单结算

| 功能 | 需求描述 |
|------|---------|
| **确认订单** | 展示结算商品列表、金额汇总（商品总额/运费/折扣/实付金额） |
| **收货地址** | 选择已有地址 / 新建地址，默认选中 |
| **提交订单** | 解析商品列表 → 校验库存 → 锁定库存 → 计算金额 → 生成订单 → 清空购物车已选 |
| **库存校验** | 可用库存 = `stock - lockedStock`，不足时拒绝下单 |

### 4.4 支付

| 功能 | 需求描述 |
|------|---------|
| **支付方式** | 支付宝 / 微信 |
| **发起支付** | 创建支付单（payNo），生成支付二维码/跳转 |
| **支付回调** | 异步回调：更新支付状态 → 更新订单状态（待支付→待发货）→ 扣减真实库存 |
| **查询状态** | 轮询/回调查询支付结果 |

### 4.5 物流追踪

| 功能 | 需求描述 |
|------|---------|
| **物流信息** | 物流单号、物流公司、物流状态 |
| **物流轨迹** | 时间线展示 JSON 物流事件 |
| **确认收货** | 用户点击确认收货 → 订单状态变更（待收货→已完成） |

### 4.6 订单管理

| 功能 | 需求描述 |
|------|---------|
| **订单列表** | 按状态 Tab 切换（全部/待付款/待发货/待收货/已完成）、分页 |
| **订单详情** | 订单号、商品明细、金额、收货地址、时间轴 |
| **取消订单** | 待支付状态可取消 → 释放锁定库存 |
| **超时取消** | 30 分钟未支付自动取消 → 释放锁定库存 |

### 4.7 个人中心

| 功能 | 需求描述 |
|------|---------|
| **收藏夹** | 收藏/取消收藏 SPU、列表查看 |
| **地址管理** | 收货地址 CRUD、设置默认地址 |
| **浏览历史** | 浏览记录列表 |

### 4.8 C 端订单状态流转

```
待支付 ──支付成功──→ 待发货 ──商家发货──→ 待收货 ──确认收货──→ 已完成
  │                    ↑                     ↑
  ├─ 超时取消           │                     │
  └─ 手动取消 → 释放库存  │                     │
      ↓                  │                     │
    已取消               支付回调              用户操作
```

## 5. AI 智能客服需求

### 5.1 对话能力

| 场景 | 触发方式 | 处理流程 |
|------|---------|---------|
| **查订单** | "帮我查一下订单 Txxx" | 意图识别 → Function Calling → 调 Spring Boot API → 格式化回复 |
| **查商品** | "红色裙子还有货吗" | ES 语义搜索 → 返回商品信息 |
| **退货咨询** | "这个能退货吗" | Function Calling → 查询订单退款资格 → 回复 |
| **物流查询** | "货到哪了" | Function Calling → 查物流轨迹 → 格式化 |
| **知识问答** | "退货政策是什么" | RAG 检索（ES dense_vector + BM25）→ LLM 增强生成 |
| **闲聊** | "你好" | 直接 LLM 回复 |

### 5.2 架构要求

```
Vue 3 聊天气泡 (SSE 打字机效果)
    ↕ EventSource
Spring Boot SseEmitter (鉴权 + 转发)
    ↕ HTTP
Python FastAPI (LangGraph Agent 编排)
    ↕ LLM API
Claude / GPT-4o
```

### 5.3 Agent 工作流 (LangGraph)

```
用户输入 → 意图识别 → 条件路由
                    ├→ 简单问答 → RAG 检索 → LLM 生成
                    ├→ 复杂任务 → Function Calling → 调用后端 API
                    ├→ 打招呼 → 直接回复
                    └→ 无法处理 → 转人工提示
                    ↓
               质量检查 (LLM 自检) → SSE 流式输出
```

### 5.4 Function Calling 工具集

| 工具名 | 触发场景 | 对应 API |
|--------|---------|---------|
| `query_order` | 查询单个订单 | `GET /api/trade/order/{orderNo}` |
| `query_user_orders` | 查询订单列表 | `GET /api/trade/order/list` |
| `query_product` | 查询商品详情 | `GET /api/product/spu/{id}` |
| `search_products` | 商品搜索 | `GET /api/search/product?keyword=...` |
| `check_return_eligibility` | 退货资格检查 | `GET /api/order/refund/check-eligibility/{orderNo}` |
| `track_logistics` | 物流查询 | `GET /api/trade/logistics/{orderNo}` |
| `query_cart` | 购物车查询 | `GET /api/trade/cart` |

### 5.5 RAG 混合检索

```
用户问题 → Query Rewrite (LLM 改写)
        → 双路召回: BM25 (关键词) + dense_vector (语义)
        → 合并 Top 20 → Rerank (LLM 精排 Top 5)
        → LLM 增强生成
```

利用 Elasticsearch 8 原生 `dense_vector` 字段，无需额外向量数据库。

### 5.6 评测体系

| 环节 | 方法 | 目标 |
|------|------|------|
| **离线评测** | 50 条测试集 × 每次改动全量回归 | 量化 Prompt/模型/检索策略变更效果 |
| **LLM-as-Judge** | 另一个 LLM 对比期望 vs 实际打分 (1-5) | 自动化质量评估 |
| **在线监控** | LangFuse Trace + 用户点赞/点踩 | 线上真实质量追踪 |
| **可对比实验** | 换模型/改 Prompt/调检索 → 指标对比 | 数据驱动迭代 |

## 6. 非功能性需求

### 6.1 高并发

| 场景 | 方案 | 目标 |
|------|------|------|
| **库存扣减** | Redis Lua 预扣 (原子) → MQ 异步削峰 → DB 乐观锁兜底 | 毫秒级响应，不超卖 |
| **商品查询** | Redis 缓存 30min TTL + 手动失效 | 减少 DB 压力 |
| **订单创建** | RabbitMQ 异步处理 + 消费速率控制 | 削峰填谷 |
| **秒杀** | Nginx 限流 + Redis 内存标记 + 异步下单 | 防刷 + 高吞吐 |

### 6.2 安全

- JWT 无状态认证，Token 有效期可配置
- 密码 BCrypt 加密存储
- CORS 白名单 + CSRF 防护
- SQL 注入防护（MyBatis-Plus 参数化查询）
- 敏感接口限流

### 6.3 数据一致性

- 库存：Redis 预扣 + DB 最终一致（定时对账）
- 订单：事务包裹核心操作，MQ 异步解耦非关键路径
- ES 搜索：binlog 增量同步 + 定时全量兜底
