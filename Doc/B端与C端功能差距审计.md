# B 端与 C 端功能差距审计

> 审计日期：2026-09-05。依据当前仓库代码、前端页面、数据库脚本与现有实现文档核对，不将需求描述直接视为已实现能力。

> 文档关联：当前架构和启动口径见《当前实现基线与文档口径》；本报告只描述差距与排期，不替代完整需求文档。

## 当前基线

- 系统实际为单 Maven 模块 Spring Boot 后端、Ant Design Vue B 端控制台、Vue 3/Vant C 端交易前台。
- C 端已具备会员认证、商品目录、购物车、结算、订单、模拟支付、物流、收藏与足迹基础能力。
- B 端已具备商品、分类、品牌、SKU、订单、退款、会员、营销、财务、税务和基础看板页面。
- Docker、Flyway、Redis 库存预占和 RabbitMQ 交易事件已接入；ES 全量同步仍为占位实现，AI 服务仍为空包目录。

## B 端主要缺口

1. 缺 Amazon/eBay/Shopify 等平台订单自动拉取、增量同步、智能审单、拆单、合单和批量面单/发票/装箱单。
2. 缺国内仓、海外仓、FBA、第三方仓、多仓库存同步、预警、补货、库龄、批次/效期/序列号、调拨、波次和扫码出入库。
3. 缺供应商、采购订单、比价、合同、委外加工与清关资料自动生成。
4. 物流目前主要是手工录入单号，缺 DHL/FedEx/UPS/USPS 对接、智能选渠道、运费计算、轨迹同步和异常工单。
5. 财务已有对账单、税率和 Excel 导出，但缺多币种汇率、订单利润、平台回款、应收应付、广告费、汇兑损益及 VAT/销售税规则。
6. 缺 B 端客户等级、差异定价、账期、询盘、代理商分润和区域保护。
7. Dashboard 只有基础数量和小时订单统计，缺 GMV、转化率、客单价、库存周转、利润率、ROI、ACOS 等多维看板。
8. JWT/RBAC 已启用，但 `DataScope` 行级权限仍未消费，操作审计、加密存储和多站点隔离尚不完整。
9. 需求要求微服务可扩展，当前仍是单模块；`order` 与 `trade` 两套模型长期并存，需统一订单领域。

## C 端主要缺口

1. 当前只有手机号密码登录，缺邮箱、Google/Facebook；游客可浏览，但加入购物车仍要求会员登录。
2. 商品仅支持 MySQL 分页、关键词和分类筛选，缺多语言、多币种、联想搜索、品牌/价格/评分/销量/时效筛选、图片/视频/评价/问答。
3. 购物车和结算基础流程已完成，但缺服务端结算快照令牌、按地址计算运费/税费和 C 端优惠券。
4. 支付仅支持开发/测试模拟支付，缺 Stripe、PayPal、信用卡、数字钱包、验签和 PCI 合规接入。
5. 缺 C 端退换货申请、凭证上传、退款进度、在线客服和 AI 客服。
6. 物流只能读取基础物流记录，缺实时轨迹、当前位置、预计送达和异常推送。
7. 收藏/足迹已有 API 和基础入口，但缺独立列表页；订单详情、完整地址编辑、售后页仍需补齐。
8. 缺推荐、弃购挽回、积分兑换、秒杀、捆绑销售、分享返利和邀请奖励。
9. 缺 IP/语言/货币/时区本地化、RTL、HTTPS、Cookie 同意、GDPR/CCPA 删除请求、隐私政策和合规标识。
10. 移动端已有响应式基础，但 320/375/390/430px 全量验收和性能指标尚未完成。

## 优先级

### P0：购买闭环稳定性

- 清理全部开发种子乱码和重复分类，统一 UTF-8 导入流程。
- 补 C 端订单详情、物流详情、取消订单、地址编辑和结算快照/token。
- 补真实支付回调验签、金额核验、支付单幂等和 ES 自动配置的开发环境隔离。

### P1：B 端运营可用性

- 多仓库存、库存预警、物流商接口、轨迹同步、批量订单处理、异常工单、数据看板和行级权限。

### P2：跨境业务扩展

- 平台订单同步、供应链采购、全球税务、多币种利润、CRM/渠道、多语言 C 端、评价售后和 AI 客服。
