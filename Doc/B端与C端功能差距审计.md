# B 端与 C 端功能差距审计

> 审计日期：2026-09-06。依据当前仓库代码、提交记录、前端构建和针对性测试复核；全量 Maven 回归与真实基础设施验收仍单独标注，不将规划或模拟数据验收视为生产能力。

> 文档关联：当前架构和启动口径见《当前实现基线与文档口径》；本报告只描述差距与排期，不替代完整需求文档。

## 当前基线

- 系统实际为单 Maven 模块 Spring Boot 后端、Ant Design Vue B 端控制台、Vue 3/Vant C 端交易前台。
- C 端已具备会员认证、商品目录、购物车、结算、订单、物流、收藏与足迹基础能力；交易路由登录拦截、订单/物流详情、结算快照 token、仅退款申请/进度已交付。
- B 端已具备商品、分类、品牌、SKU、订单、会员、营销、财务、税务和基础看板页面；退款页已接入交易退款审核与处理备注反馈。
- Docker、Flyway、Redis 库存预占和 RabbitMQ 交易事件已接入；ES 通过配置开关隔离但索引同步仍不完整，AI 服务仍为空包目录。

### 2026-09-06 交付与验证记录

- 已交付支付宝 RSA2 回调验签、支付金额/订单归属校验、支付幂等；开发模拟支付仍只在 `application-dev.yml` 开启。
- 已交付独立 `trade_refund` 退款域：C 端本人待发货订单仅退款，B 端审核通过/驳回/确认退款。
- 已验证支付回调、结算快照、交易退款、购物车/订单归属等针对性单元测试；B/C 端生产构建；C 端 320/375/390/430px 与 1440px 模拟视口无横向溢出。
- 未闭合真实数据库迁移与完整 Maven 回归；本机 JDK 23 全量编译曾出现“无法关闭编译器资源”，测试上下文还需在稳定工具链和可用 MinIO/Docker 环境下复验。

## B 端主要缺口

1. 缺 Amazon/eBay/Shopify 等平台订单自动拉取、增量同步、智能审单、拆单、合单和批量面单/发票/装箱单。
2. 缺国内仓、海外仓、FBA、第三方仓、多仓库存同步、预警、补货、库龄、批次/效期/序列号、调拨、波次和扫码出入库。
3. 缺供应商、采购订单、比价、合同、委外加工与清关资料自动生成。
4. 物流目前主要是手工录入单号，缺 DHL/FedEx/UPS/USPS 对接、智能选渠道、运费计算、轨迹同步和异常工单。
5. 财务已有对账单、税率和 Excel 导出，但缺多币种汇率、订单利润、平台回款、应收应付、广告费、汇兑损益及 VAT/销售税规则。
6. 缺 B 端客户等级、差异定价、账期、询盘、代理商分润和区域保护。
7. Dashboard 只有基础数量和小时订单统计，缺 GMV、转化率、客单价、库存周转、利润率、ROI、ACOS 等多维看板。
8. JWT/RBAC 已启用，但 `DataScope` 行级权限仍未消费，操作审计、加密存储和多站点隔离尚不完整。
9. 需求要求微服务可扩展，当前仍是单模块；`order` 与 `trade` 两套模型长期并存，需统一订单领域。

## C 端主要缺口

1. 当前只有手机号密码登录，缺邮箱、Google/Facebook；游客可浏览，但加入购物车仍要求会员登录。
2. 商品仅支持 MySQL 分页、关键词和分类筛选，缺多语言、多币种、联想搜索、品牌/价格/评分/销量/时效筛选、图片/视频/评价/问答。
3. 购物车和结算基础流程已完成，服务端结算快照令牌已补齐；仍缺按地址计算运费/税费和 C 端优惠券。
4. 支付仅支持开发/测试模拟支付，缺 Stripe、PayPal、信用卡、数字钱包、验签和 PCI 合规接入。
5. C 端仅退款申请与进度已实现；仍缺退货退款、凭证上传、真实原路退款、在线客服和 AI 客服。
6. 物流只能读取基础物流记录，缺实时轨迹、当前位置、预计送达和异常推送。
7. 收藏/足迹已有独立列表页，订单详情、物流详情、完整地址编辑和仅退款售后入口已补齐；仍缺商品评价关联、售后凭证与退货物流。
8. 缺推荐、弃购挽回、积分兑换、秒杀、捆绑销售、分享返利和邀请奖励。
9. 缺 IP/语言/货币/时区本地化、RTL、HTTPS、Cookie 同意、GDPR/CCPA 删除请求、隐私政策和合规标识。
10. 响应式前台已具备移动（≤680px 单列 + 底部导航）与桌面（≥1025px 顶栏导航 + 商品网格）两套布局，320/375/390/430px 与 1440px 视口验收已通过；仍需补齐触控与悬停状态的差异化细节、性能指标和真机回归。
